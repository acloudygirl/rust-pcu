### 这是我在复习 408 计算机组成原理时写的一个 Rust 实践项目。

• 相比单纯看书和刷题，我希望通过自己模拟一个简化 CPU，把“指令如何被取出、如何译码、ALU 如何执行、内存如何读写、
  PC 如何跳转、控制信号如何影响数据通路”这些内容真正串起来，而不是只学会做题却不会实践

  项目当前以 RV32I 为基础，实现了一个简化的单周期 CPU，并为后续流水线控制预留了一部分逻辑。这个项目更像是一份可
  运行的学习笔记：代码负责表达我对 CPU 执行过程的理解，注释和文档负责记录推导过程，而大量单元测试则用来验证每个
  知识点是否真的理解清楚。
